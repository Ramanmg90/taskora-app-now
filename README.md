# تسکورا (Taskora) — اپ اندروید آفلاین

این یک پروژه‌ی **کامل فلاتر** است (شامل کد Dart در `lib/` و پوشه‌ی کامل `android/`).
همه‌چیز (حساب کاربری، وظایف، دسته‌بندی‌ها، یادآوری‌ها، تقویم شمسی) با پایگاه‌داده‌ی محلی
SQLite روی خود گوشی ذخیره می‌شود؛ نیازی به سرور یا اینترنت (به‌جز برای دانلود اولیه‌ی
ابزارها) ندارد.

---

## پیش‌نیازها (فقط یک‌بار روی سیستم خودتان نصب می‌شود)

1. **Flutter SDK** نسخه‌ی پایدار جدید: https://docs.flutter.dev/get-started/install
2. **Android Studio** به همراه Android SDK: https://developer.android.com/studio
   - بعد از نصب Android Studio، از منوی `More Actions > SDK Manager` مطمئن شوید
     حداقل یک `Android SDK Platform` (مثلاً API 34 یا 35) نصب است.
3. بعد از نصب Flutter، در ترمینال بزنید:
   ```
   flutter doctor
   ```
   هر موردی که علامت ❌ داشت را طبق راهنمایی خودش برطرف کنید. معمولاً کافی است:
   ```
   flutter doctor --android-licenses
   ```
   را بزنید و همه را با `y` قبول کنید.

> نکته: کامپیوتر شما هنگام باز کردن پروژه در Android Studio (مرحله‌ی Gradle Sync) باید
> به اینترنت وصل باشد، چون ابزارهای Gradle و کتابخانه‌های اندروید برای بار اول دانلود
> می‌شوند. این کاملاً عادی است و فقط بار اول طول می‌کشد.

## مراحل باز کردن و اجرای پروژه

1. فایل zip را در یک مسیر ساده (مثلاً `C:\taskora` یا `~/taskora`) از حالت فشرده خارج کنید.
2. Android Studio را باز کنید و از صفحه‌ی اول گزینه‌ی **Open** را بزنید.
3. پوشه‌ای را انتخاب کنید که مستقیماً فایل `pubspec.yaml` داخلش است (همان پوشه‌ی
   ریشه‌ی پروژه، نه پوشه‌ی `lib` یا `android`).
4. صبر کنید Android Studio افزونه‌ی Flutter/Dart را تشخیص دهد و پروژه را ایندکس کند.
   اگر پیغام نصب پلاگین Flutter/Dart را دید، تأیید کنید.
5. Gradle به‌صورت خودکار Sync می‌شود (پایین صفحه یک نوار پیشرفت می‌بینید). این مرحله
   ممکن است چند دقیقه طول بکشد (دانلود Gradle + وابستگی‌ها).
   - اگر پیغامی درباره‌ی «Gradle wrapper یافت نشد» دیدید، گزینه‌ی پیشنهادی برای
     ساخت خودکار wrapper را تأیید کنید (فایل کوچک `gradle-wrapper.jar` به‌خاطر
     محدودیت محیط ساخت این پروژه از قبل داخلش نبود و همینجا دانلود می‌شود).
6. یک گوشی اندرویدی را با کابل USB وصل کنید و «اشکال‌زدایی USB» (USB debugging) را
   در تنظیمات گوشی فعال کنید — یا از منوی بالا یک Android Emulator بسازید و اجرا کنید
   (`Device Manager > Create Device`).
7. در نوار بالای Android Studio دستگاه را از لیست انتخاب کنید و دکمه‌ی سبز رنگ ▶️ (Run)
   را بزنید. اپ روی گوشی/شبیه‌ساز نصب و اجرا می‌شود.

## گرفتن فایل نصبی APK برای اشتراک‌گذاری

اگر می‌خواهید فقط فایل نصبی (APK) بسازید تا روی گوشی دیگری هم نصب کنید:

- از داخل Android Studio: منوی `Build > Flutter > Build APK` (یا `Build > Build Bundle(s) / APK(s) > Build APK(s)`).
- یا از ترمینال، داخل پوشه‌ی پروژه:
  ```
  flutter build apk --release
  ```
  فایل نهایی در مسیر `build/app/outputs/flutter-apk/app-release.apk` ساخته می‌شود.

## اگر خطای مربوط به نسخه‌ی Gradle/AGP/Kotlin دیدید

نسخه‌های زیر در پروژه تنظیم شده‌اند و با نسخه‌های امروزیِ Flutter سازگارند:

- Gradle: 8.10.2
- Android Gradle Plugin (AGP): 8.7.3
- Kotlin: 2.1.0
- compileSdk / targetSdk: 35
- minSdk: 23 (یعنی اندروید ۶ به بالا)

اگر Android Studio پیشنهاد داد این نسخه‌ها را «Upgrade» کنید، معمولاً مشکلی نیست و
می‌توانید قبول کنید.

## ساختار پروژه

```
taskora_flutter/
├── android/          # پروژه‌ی کامل اندروید (Gradle, Manifest, آیکون و ...)
├── lib/
│   ├── main.dart      # نقطه‌ی شروع برنامه
│   ├── app.dart        # تنظیمات MaterialApp
│   ├── db/              # SQLite (sqflite)
│   ├── models/           # مدل‌های داده (Task, TaskCategory, AppUser)
│   ├── services/           # منطق دیتابیس، احراز هویت، اعلان‌ها، تقویم شمسی
│   ├── providers/            # مدیریت state با Provider
│   ├── screens/                # صفحات UI
│   └── widgets/                  # کامپوننت‌های قابل استفاده‌ی مجدد
└── pubspec.yaml
```

## قابلیت‌ها

- ثبت‌نام / ورود آفلاین (رمز عبور با SHA-256 هش می‌شود، همه‌چیز فقط روی خود گوشی است)
- مدیریت وظایف با اولویت، وضعیت، دسته‌بندی و توضیحات
- تقویم شمسی اختصاصی (بدون وابستگی به پکیج خارجی برای تبدیل تاریخ)
- یادآوری با اعلان محلی (Local Notifications) با چند بازه‌ی زمانی قابل انتخاب
- پوسته‌ی روشن/تیره
- داشبورد با آمار کلی و لیست وظایف امروز/عقب‌افتاده/آینده/تکمیل‌شده
